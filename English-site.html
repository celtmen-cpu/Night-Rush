How to Install?

Windows

Download the game from this website and open it.

Mac

Download the game from this website, then open the .dmg file and drag the application into your Mac's Applications folder.

Android

Download the game from this website, then open the .apk file. After that, you may be warned that this game does not come from a recognized developer. If this happens, tap More information, then Install anyway.

iPhone

Download AltStore from https://altstore.io/download, then open the app. After that, go to the Sources tab at the bottom of the screen, search for AltStore, and tap View All Apps. Find AltStore Classic and install it.

Next, open the app and go to Sources. Tap the + button and add the following URL:

https://celtmen-cpu.github.io/Night-Rush/source.json

Then tap Add Source. Install AltServer on your PC or Mac and sign in through AltServer as well.

Finally, install Night Rush. You will be asked for an Apple ID and password. Use the credentials of a free Apple Developer account.

When prompted to enable Developer Mode on your iPhone, do so and then trust your Apple ID.

Note: You will need to refresh the applications at least once every 7 days.
