How to Install?

Windows

Download the game from this website and open it.

Mac

Download the game, open the .dmg file, then drag the application into your Applications folder.

Android

Download the game, open the .apk file. If a warning appears, tap “More info” then “Install anyway”.

iPhone

Download AltStore from https://altstore.io/download and install it. Then go to Sources, add:

https://celtmen-cpu.github.io/Night-Rush/source.json

Install AltServer on PC/Mac, sign in, and install Night Rush.

Enable Developer Mode if required. Apps must be refreshed every 7 days.
