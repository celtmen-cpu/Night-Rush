¿Cómo instalar?

Windows

Descarga el juego desde este sitio web y ábrelo.

Mac

Descarga el juego, abre el archivo .dmg y arrastra la aplicación a la carpeta Aplicaciones.

Android

Descarga el juego y abre el archivo .apk. Si aparece una advertencia, pulsa «Más información» y luego «Instalar de todos modos».

iPhone

Descarga AltStore desde https://altstore.io/download e instala AltStore Classic. Añade la fuente:

https://celtmen-cpu.github.io/Night-Rush/source.json

Instala AltServer en PC/Mac, inicia sesión con tu Apple ID y luego instala Night Rush.

Activa el modo desarrollador si se solicita. La renovación es necesaria cada 7 días.
