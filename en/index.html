How to install?

Windows

Download the game from this site and run it.

Mac

Download the game, open the .dmg file, then drag the application into the « Applications » folder.

Android

Download the game and open the .apk file. If a warning message appears, click on « More information », then on « Install anyway ».

iPhone

Download AltStore from https://altstore.io/download and install AltStore Classic.
Add the source:

or copy this link into AltStore Classic: https://celtmen-cpu.github.io/CeltmenApps/source.json

Install AltServer on PC/Mac, sign in with your Apple ID, then install Night Rush.

Enable developer mode if prompted. Renewal is required every 7 days.
