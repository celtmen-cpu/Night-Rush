Comment installer ?

Windows

Téléchargez le jeu puis ouvrez-le.

Mac

Téléchargez le jeu, ouvrez le fichier .dmg puis glissez l’application dans le dossier Applications.

Android

Téléchargez le fichier .apk puis autorisez l’installation depuis une source inconnue si demandé.

iPhone

Téléchargez AltStore depuis https://altstore.io/download, puis installez AltServer sur PC ou Mac. Connectez votre iPhone à AltServer. Ajoutez ensuite la source : https://celtmen-cpu.github.io/Night-Rush/source.json Installez l’application via AltStore avec un identifiant Apple (compte développeur gratuit). Activez le mode développeur si demandé. Note : l’application doit être rafraîchie tous les 7 jours.
