How to Install?

Windows

Download the game from this website and open it.

Mac

Download the game, open the .dmg file, then drag the application into the Applications folder.

Android

Download the game and open the .apk file. If a warning appears, click "More information" then "Install anyway".

iPhone

Download AltStore from https://altstore.io/download and install AltStore Classic. Add the source:

https://celtmen-cpu.github.io/Night-Rush/source.json

Install AltServer on PC/Mac, sign in with your Apple ID, then install Night Rush.

Enable Developer Mode if requested. Renewal is required every 7 days.
