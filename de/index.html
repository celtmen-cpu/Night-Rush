Wie installiere ich?

Windows

Laden Sie das Spiel von dieser Website herunter und starten Sie es.

Mac

Laden Sie das Spiel herunter, öffnen Sie die .dmg-Datei, ziehen Sie die Anwendung dann in den « Programme »-Ordner.

Android

Laden Sie das Spiel herunter und öffnen Sie die .apk-Datei. Wenn eine Warnmeldung erscheint, klicken Sie auf « Weitere Informationen », dann auf « Trotzdem installieren ».

iPhone

Laden Sie AltStore von https://altstore.io/download herunter und installieren Sie AltStore Classic. Fügen Sie die Quelle hinzu:

Quelle hinzufügen

oder kopieren Sie diesen Link in AltStore Classic: https://celtmen-cpu.github.io/CeltmenApps/source.json

Installieren Sie AltServer auf PC/Mac, melden Sie sich mit Ihrer Apple-ID an, dann installieren Sie Night Rush.

Aktivieren Sie den Entwicklermodus, wenn Sie dazu aufgefordert werden. Die Erneuerung ist alle 7 Tage erforderlich.
